# JSKMU — Jaswant Singh Khalra Missing & Unidentified

A free, pan-India platform that helps match missing person reports with
unidentified body records. Built and run solo, free for everyone.

**Live:** [jskmu.in](https://jskmu.in)

## Stack

Next.js · Supabase (Postgres) · Tailwind · Vercel

## What it does

- Public reporting for missing persons and unidentified bodies
- Rule-based matching between the two databases
- Role-based dashboards for different user types
- Photo uploads, with row-level security enforced at the database level
- Bilingual awareness poster generator (PDF + QR)
